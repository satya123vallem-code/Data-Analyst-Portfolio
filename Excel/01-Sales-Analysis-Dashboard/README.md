# 📊 Sales Analysis Dashboard – Excel

## 📌 Project Overview

This project demonstrates an end-to-end Sales Analysis Dashboard built using Microsoft Excel.

The objective of this project was to transform raw sales data into a structured and interactive dashboard that can help users analyze sales performance and identify useful business insights.

The project covers data preparation, lookup functions, calculations, data validation, Pivot Tables, Pivot Charts, Slicers, Timeline, and dashboard development.

---

## 🎯 Business Objective

The main objective of this project is to analyze sales data and create an interactive dashboard that allows users to:

- Analyze sales performance
- Identify sales trends
- Filter data by different categories
- Compare business performance across different periods
- Quickly understand key sales metrics

## 🔄 Project Workflow

### 1. Project Walkthrough

Reviewed the source data and understood the structure and requirements of the project.

### 2. XLOOKUP

Used XLOOKUP to retrieve required information from related data.

### 3. INDEX + MATCH

Used INDEX + MATCH for flexible lookup and data retrieval.

### 4. Sales Calculation

Created multiplication formulas to calculate sales values based on the available data.

### 5. Multiple IF Functions

Used multiple IF conditions to classify and analyze data based on business rules.

### 6. Date Formatting

Standardized date formats to make the data suitable for analysis and reporting.

### 7. Number Formatting

Applied appropriate number and currency formats to improve readability.

### 8. Duplicate Check

Checked the dataset for duplicate records to improve data quality.

### 9. Convert Range to Table

Converted the raw data range into an Excel Table to make the dataset easier to manage and analyze.

### 10. Pivot Tables & Pivot Charts

Created Pivot Tables and Pivot Charts to summarize and visualize sales data.

### 11. Timeline

Added a Timeline to enable users to filter the dashboard based on dates.

### 12. Slicers

Added interactive Slicers to filter and analyze the data by different categories.

### 13. Updating Pivot Table Data Source

Updated the Pivot Table data source when the underlying dataset changed.

### 14. Dashboard Development

Built an interactive Sales Dashboard by combining Pivot Tables, Pivot Charts, Slicers, and Timeline.
