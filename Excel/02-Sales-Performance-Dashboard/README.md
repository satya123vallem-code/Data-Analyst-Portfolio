#  Sales Performance Dashboard – Excel

##  Project Overview

This project demonstrates an interactive **Sales Performance Dashboard built using Microsoft Excel**.

The objective of this project was to analyze sales performance through key business metrics and interactive visualizations. The dashboard provides a consolidated view of revenue, orders, quantity sold, average order value, regional performance, product category performance, sales channel performance, and top-performing products.

---

## 🎯 Business Objective

The main objective of this project is to create an interactive dashboard that helps users:

- Monitor overall sales performance
- Analyze revenue trends over time
- Compare revenue across regions
- Analyze product category performance
- Compare different sales channels
- Identify top-performing products
- Filter and explore sales data interactively

##  Key Performance Indicators

The dashboard includes the following KPIs:

###  Total Revenue

Displays the overall revenue generated from sales.

###  Total Orders

Shows the total number of orders.

###  Total Quantity Sold

Displays the total quantity of products sold.

###  Average Order Value

Shows the average revenue generated per order.

---

## 📈 Dashboard Analysis

### 1. Revenue by Month

Analyzes monthly revenue trends and helps identify changes in sales performance throughout the year.

### 2. Revenue by Region

Compares revenue performance across different regions:

- Central
- East
- North
- South
- West

### 3. Revenue by Product Category

Analyzes revenue generated by different product categories, including:

- Computers
- Monitors
- Networking
- Storage
- Accessories
- Office Supplies

### 4. Revenue by Sales Channel

Compares revenue across different sales channels:

- Corporate Sales
- Marketplace
- Online
- Retail Store

### 5. Top 5 Products by Revenue

Identifies the top five products based on revenue generated.
